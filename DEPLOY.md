# Как разместить эту CRM в интернете (простая инструкция)

Эта инструкция написана для человека без опыта программирования. Она использует
два бесплатных сервиса — **Railway** (там будет жить backend и база данных) и
**Vercel** (там будет жить сайт, который видят люди). Домен и его настройки —
на вашем рег.ру.

Весь процесс — это работа мышкой в браузере, без установки программ и без
командной строки. Понадобится где-то 30-40 минут.

---

## Шаг 0. Что вообще происходит

CRM состоит из двух частей:
- **Backend** — программа, которая хранит данные, общается с Авито, отвечает на
  запросы. Она должна работать 24/7 на сервере.
- **Frontend** — сайт, который вы открываете в браузере (то, что вы видите).

Они будут жить на разных адресах в интернете, а домен с рег.ру мы "привяжем" к
обеим частям (например, `crm.вашдомен.ru` — сайт, `api.вашдомен.ru` — backend).

---

## Шаг 1. Загрузить код на GitHub

GitHub — это просто "облачная папка" для кода, откуда Railway и Vercel будут
брать ваш проект.

1. Зайдите на https://github.com и зарегистрируйтесь (если нет аккаунта).
2. Нажмите **New repository** (зелёная кнопка).
3. Назовите репозиторий, например `avito-crm`. Оставьте его **Private**
   (приватным — это важно, там будут ваши ключи). Нажмите **Create repository**.
4. На следующей странице найдите ссылку **uploading an existing file** —
   нажмите на неё.
5. Откройте папку с проектом на компьютере (которую вы скачали из этого чата,
   распакованную из zip), выделите ВСЁ содержимое папки `avito-crm` (все файлы
   и подпапки `backend`, `frontend`, `README.md` и т.д.) и перетащите их в
   окно браузера на странице GitHub.
6. Внизу страницы нажмите **Commit changes**. Подождите, пока файлы загрузятся.

Готово — код теперь в интернете (но пока приватно, его никто кроме вас не видит).

---

## Шаг 2. Backend + база данных на Railway

1. Зайдите на https://railway.app, зарегистрируйтесь **через GitHub**
   (кнопка "Login with GitHub") — это свяжет аккаунты автоматически.
2. Нажмите **New Project → Deploy from GitHub repo**, выберите ваш репозиторий
   `avito-crm`.
3. Railway спросит про папку — укажите **Root Directory**: `backend`
   (это делается в настройках сервиса — Settings → Root Directory).
4. В том же проекте нажмите **+ New → Database → PostgreSQL** — это добавит
   базу данных автоматически. Railway сам создаст переменную `DATABASE_URL`
   и свяжет её с backend.
5. Откройте сервис backend → вкладка **Variables** — добавьте переменные:
   - `JWT_SECRET` — любой длинный случайный набор символов (например,
     напечатайте 40 случайных букв и цифр подряд)
   - `PORT` — `4000`
   - `PUBLIC_BASE_URL` — временно оставьте `https://placeholder.com`
     (вернёмся к этому в Шаге 5)
6. Убедитесь, что в Settings backend-сервиса указаны команды:
   - Build Command: `npm install && npm run build`
   - Start Command: `npm run start`
7. Нажмите **Deploy**. Через пару минут Railway выдаст вам адрес вида
   `https://avito-crm-backend-production.up.railway.app` — это и есть адрес
   вашего backend. Сохраните эту ссылку.

Проверка: откройте `<ваша ссылка>/health` в браузере — должно появиться
`{"ok":true}`. Если появилось — backend работает.

---

## Шаг 3. Сайт (frontend) на Vercel

1. Зайдите на https://vercel.com, зарегистрируйтесь **через GitHub**.
2. Нажмите **Add New → Project**, выберите тот же репозиторий `avito-crm`.
3. В настройках проекта укажите **Root Directory**: `frontend`.
4. В разделе **Environment Variables** добавьте:
   - `VITE_API_URL` = адрес backend из Шага 2 (например,
     `https://avito-crm-backend-production.up.railway.app`)
5. Нажмите **Deploy**. Через пару минут Vercel выдаст адрес вида
   `https://avito-crm.vercel.app` — откройте его, должна открыться страница
   входа в CRM.

На этом этапе CRM уже полностью работает в интернете, просто на "технических"
адресах Vercel/Railway вместо вашего домена. Дальше — просто красивая обёртка
в виде вашего домена.

---

## Шаг 4. Привязка вашего домена с рег.ру

### Сайт (frontend) → ваш домен

1. В Vercel откройте проект → **Settings → Domains** → введите ваш домен
   (например, `crm.вашдомен.ru` — рекомендую именно поддомен, а не сам
   `вашдомен.ru`, если на нём уже что-то есть).
2. Vercel покажет, какую запись добавить — обычно это **CNAME**, что-то вида:
   ```
   Тип: CNAME
   Имя: crm
   Значение: cname.vercel-dns.com
   ```
3. Зайдите в панель управления рег.ру → раздел **DNS-серверы** / **Управление
   зоной DNS** для вашего домена → добавьте именно такую запись, как показал
   Vercel (скопируйте значения точно).

### Backend → поддомен api

1. В Railway откройте backend-сервис → **Settings → Networking → Custom Domain**
   → введите, например, `api.вашдомен.ru`.
2. Railway покажет CNAME-запись — так же добавьте её в DNS на рег.ру.

DNS обновляется не мгновенно — обычно 10–60 минут, иногда до нескольких часов.

---

## Шаг 5. Финальная настройка

1. В Railway → Variables backend-сервиса замените `PUBLIC_BASE_URL` на
   `https://api.вашдомен.ru` (ваш настоящий адрес backend). Сохраните — Railway
   перезапустит сервис.
2. В Vercel → Variables убедитесь, что `VITE_API_URL` = `https://api.вашдомен.ru`,
   если меняли — пересоберите проект (кнопка **Redeploy**).
3. Откройте `https://crm.вашдомен.ru` — зарегистрируйте компанию.
4. Зайдите в **Настройки → Аккаунты Авито** → подключите ваш аккаунт (client_id
   и client_secret — те, что вы мне давали, они у вас должны быть сохранены
   в личном кабинете developers.avito.ru). Так как теперь `PUBLIC_BASE_URL`
   настоящий, вебхук зарегистрируется автоматически — заявки начнут приходить.

## Как пригласить сотрудников

**Настройки → Пользователи и роли → Добавить сотрудника** — укажите его email
и придумайте ему пароль, сообщите его сотруднику. Он заходит на тот же адрес
`https://crm.вашдомен.ru` под своим email/паролем.

---

## Если что-то не работает — куда смотреть

- **Сайт не открывается** — проверьте в Vercel, что деплой прошёл успешно
  (статус "Ready", без красных ошибок в логах).
- **Заявки с Авито не приходят** — в Настройки → Аккаунты Авито должно быть
  написано "Авторизация ОК" и "вебхук зарегистрирован". Если нет — нажмите
  "Повторить подключение".
- **Ошибка при входе/регистрации** — проверьте в Railway, что backend "Ready"
  и что база данных (Postgres) подключена (переменная `DATABASE_URL` видна
  автоматически в Variables backend-сервиса).

Оба сервиса (Railway и Vercel) бесплатны для такого объёма нагрузки на старте;
если команда вырастет, там же в интерфейсе можно перейти на платный план в
один клик — без переезда и перенастройки.
